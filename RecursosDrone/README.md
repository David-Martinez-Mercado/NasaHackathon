# RecursosDrone

Material relacionado con el **dron**: fotos aéreas RGB de prueba, ortomosaicos, multiespectrales, fichas de la cámara/dron, EXIF de ejemplo.

- Lo usa `analista-dron` (índices VARI/ExG → mapa de zonas débiles) y `qa-tester` (imágenes de prueba).
- No subir imágenes con ubicación real de un agricultor sin quitar el EXIF GPS (ver `ciberseguridad`).
- Si un archivo pesa mucho, no lo metas al repositorio: anota su ubicación en un `enlaces.md`.
