# RecursosNASA — SOLO LECTURA

Material que viene **directamente de la NASA** (convocatoria Space Apps, pestaña Resources, datasets, PDFs, guías, APIs).
Ejemplos: PDFs del reto, CSV/NetCDF/GeoTIFF descargados de Earthdata/NASA POWER, archivo `enlaces.md` con URLs oficiales.

- Nadie modifica ni borra aquí; solo se añaden archivos nuevos.
- Lo analiza `analizador-recursos` → `docs/fichas/` y `docs/catalogo-datos.md`.
- Citar siempre la fuente como `RecursosNASA/<archivo>` o la URL.
