# RecursosExternos

Recursos **menos críticos o de terceros**: logos, íconos, imágenes de marca, tipografías, referencias visuales, fuentes no-NASA
(artículos agronómicos, datos INEGI/SIAP/CONAGUA, etc.) y cualquier material del proyecto que no sea de la NASA ni del dron.

- Los usan `frontend-agricultor` y `pitch-presentacion` (logos, imágenes) y `agronomo-reglas` (fuentes agronómicas externas).
- Anotar la fuente y la licencia de cada archivo en `fuentes.md` dentro de esta carpeta. Si no se conoce: `[POR VERIFICAR]`.
- Un dato técnico de aquí NO tiene el mismo peso que uno de `RecursosNASA/`: indícalo al citarlo.
